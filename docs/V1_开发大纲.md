# 口袋钓鱼王 · V1 开发大纲

> 本文档为V1版本的唯一对齐依据，所有开发必须围绕本大纲进行。
> 引擎：Unity 2022.3.62f2；核心流程以 `Assets/Scenes/SampleScene.unity` 为准。

---

## 1. 风格与核心玩法基调
- 钓鱼模仿的是星露谷的钓鱼玩法。
- 美术风格：像素、夸张、搞笑、可爱。

## 2. 场景与UI设计
1) 家（Home）：包含以下6个按钮
   - 背包（查看鱼竿和材料）
   - 鱼箱（可以出售鱼）
   - 任务
   - 图鉴（V1不做自由布置功能）
   - 钓鱼（出现地图，可选择钓鱼场地）
   - 商店

2) 商店（Shop）：
   - 升级渔具
   - 售卖特定的“核心材料”

3) 钓鱼场地（Fishing Spot）：通过点击钓鱼地图进入。包含以下5个按钮
   - 背包
   - 鱼箱（不可出售鱼）
   - 任务
   - 图鉴（V1不做自由布置功能）
   - 回家

## 3. 鱼获系统
1) 鱼种：与钓鱼地点、时间有关，不同的鱼稀有程度不同。

2) 鱼行为：四套逻辑，相互组合，变化出各种不同的鱼。
   - 通用参数：进度条上涨、下降速度。
   - i. 平滑移动系：鱼平滑地移动到目标点。
     - 参数：鱼移动速度，鱼思考等待时间范围
   - ii. *位置跳跃系：鱼停顿一段时间，然后瞬间出现在一个新位置。
   - iii. *状态切换系：鱼有两种或以上的状态，比如“慢速”和“快速”，并根据条件切换。
   - iv. *随机抖动系：鱼高频率地、在一定范围内随机移动。

3) *垃圾：与钓鱼地点有关。
   - 垃圾行为：固定一个位置不动，轻的在上面，重的在底部。

4) 宝箱：与钓鱼地点有关，有概率出现普通宝箱和高级宝箱，随鱼一同钓出。

5) 鱼长度：与品质有关。

6) 品质：
   - i. 品质划分：勉强上钩（最差）；像模像样；史诗对决；吹牛资本（最好）。
   - ii. 品质与进度条下降次数有关，从最好到最差：0次，1次，2次，3次及以上。

## 4. 渔具系统
1) 鱼竿：控制鱼线最大长度、上鱼速度。
   - 品质：我的树枝；丈母娘的认可；遥遥领先；直接上岸；功德+1。

2) 鱼箱：用来放鱼，更好的鱼箱可以放更多的鱼。

3) 鱼饵：
   - i. 鱼饵等级：高等级鱼饵可以提高稀有鱼上钩概率。
   - ii. 特种鱼饵：提高钓到的某种鱼的概率。

## 5. 鱼网系统
1) 根据离线时间计算收益，容量有限。

2) 每一个钓点都有一个鱼网。

## 6. 钓鱼场地
1) 不同地点，可钓上来的鱼不同。

2) 地点：小溪，森林湖，公厕马桶，海滩。

## 7. 体力系统
1) 体力按照现实时间慢慢恢复。

2) 体力为零无法钓鱼。

3) 看广告回满体力。

## 8. 经济系统
- 经济闭环：钓鱼 -> 卖鱼换金币 -> 用金币+材料升级渔具。
  1) 钓上来的鱼可以进行出售。
  2) 品质越好，价格就越高。
  3) 金币用途：升级渔具。

## 9. 材料系统
1) 基础材料：收集材料用于制作鱼竿。
   - 获取途径：垃圾，宝箱。
   - 种类罗列：
     - 浮木，沉船木板，湿滑的鹅卵石，缠绕的铜线，生锈的螺丝，古老的钱币，发光的珊瑚，猫猫鱼的照片。

2) 核心材料：收集材料用于制作鱼竿。
   - 获取途径：商店（昂贵），宝箱。
   - 种类：一瓶好酒，发布会PPT，一个躺椅，电子木鱼。

## 开发原则与边界（V1）
- 原则：先跑通“钓鱼 -> 卖鱼 -> 升级”的核心闭环，其余系统按本大纲逐步补全。
- UI引用：新增面板与按钮采用Inspector暴露引用，遵循`GameFlowManager`/`FishingMiniGameManager`现有管理方式。
- 数据驱动：鱼类、垃圾、宝箱均以`CatchableData`派生资产驱动；鱼行为以`FishAction`序列配置。

## 里程碑（建议）
- M1 可钓鱼：进入钓鱼场地，触发钓鱼小游戏，能结算获得鱼/垃圾/宝箱。
- M2 可出售：在“家”的鱼箱面板出售鱼获得金币。
- M3 可升级：在商店消耗金币与材料升级渔具，影响钓鱼表现（线长/上鱼速度/容量等）。
- M4 多样性：不同场地与时间影响鱼种与稀有度；至少2种鱼行为组合上线。

   - [ ] 至少实现“平滑移动系”鱼行为，可生成鱼/垃圾/宝箱实例并落入背包。

- [ ] **M2 可出售**

   - [ ] 支持批量或单个出售，并将金币计入玩家钱包。
   - [ ] 出售后库存、金币、日志提示（或动画）即时更新。

- [ ] **M3 可升级**

   - [ ] 实现鱼箱容量升级：库存上限生效并在UI中可见。

   - [ ] 根据时间段或场景切换鱼种权重，验证稀有度差异。
   - [ ] 图鉴可记录已捕获鱼的基础信息（名称、品质最高纪录、长度最值）。

## 验收标准清单
- [ ] **核心循环**：完成一次钓鱼后可出售，并用所得资源达成一次渔具升级。
- [ ] **手感反馈**：钓鱼小游戏具备至少两种鱼行为，且品质评价对结算收益产生可感知影响。
- [ ] **经济平衡**：鲸鱼、垃圾、宝箱的产出与金币、材料的消耗平衡；不存在轻易刷爆金币的途径。
- [ ] **UI一致性**：所有场景/面板交互按钮风格统一，文本双语或与现有文案风格保持一致。
- [ ] **数据驱动**：所有可钓物体（鱼、垃圾、宝箱）由`CatchableData`派生资产配置，行为序列通过`FishAction`多态实现。
- [ ] **存档安全**：背包、鱼箱、渔具等级、金币等关键数据可在退出重进后正确恢复。
- [ ] **性能与稳定**：在目标设备上运行10分钟无崩溃，钓鱼场景帧率稳定（>55 FPS 目标平台），无明显资源泄漏。
- [ ] **可追踪性**：关键系统（钓鱼结算、出售、升级）均有日志输出或调试面板便于定位问题。

> 注：若与现有实现有差异，以本大纲为准，后续变更请通过PR更新本文件。
